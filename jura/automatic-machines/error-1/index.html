Jura Error 1: thermoblock sensor fault

Error 1 bedeutet: Coffee thermoblock temperature sensor fault (S/X/J/Z family); damaged sensor on F/E80.

Kurzantwort. The control board cannot get a sane reading from the temperature sensor on the coffee thermoblock. A cold machine straight from a cold car or garage can trigger it; otherwise the sensor, its cable, or the thermal-fuse cords that feed the thermoblock have failed.

Error 1 beheben

  1. Unplug for five minutes, let the machine sit at room temperature for an hour if it has been cold, and restart.
  2. If it clears, it was temperature. If it returns instantly on a warm machine, the sensor circuit is open.
  3. Opening a Jura needs the oval-head (Torx-Plus security) driver. With the cover off, check the sensor plug on the thermoblock and the thermal-fuse cords for a broken link.
  4. Replace the NTC sensor (cheap) and the fuse cords together; if the thermoblock itself is scaled solid, replace it.

Wann aufhören und zum Reparateur gehen

Jura cases are held with security screws and the thermoblocks carry mains voltage. If you are not set up for that, this is a bench repair.

Was es kostet

Ersatzteile: Genuine Jura NTC sensor about $25 to $40; thermal-fuse cord set $15 to $30; a thermoblock $90 to $180.

Service: Der Herstellerservice für einen Vollautomaten liegt außerhalb der Garantie typisch bei 250–500 € inkl. Rückversand; freie Espressowerkstätten sind bei einem einzelnen Teil meist günstiger.

Reparatur lohnend? Yes on S, Z, GIGA and newer E-series; on a 10-year-old Impressa weigh the quote against a refurbished unit.

Error 1 beim Start oder im Betrieb?

An Jura tritt Error 1 jederzeit auf. Es gibt kein zuverlässiges Muster — nehmen Sie jedes Auftreten ernst.

Kann man die Maschine mit Error 1 weiter benutzen?

Der laufende Kaffee lässt sich meist noch fertig beziehen, aber ignorieren Sie den Code nicht: Der Defekt heilt nicht von selbst. Beginnen Sie mit den kostenlosen Prüfungen.

Verschwindet Error 1 von selbst?

Selten. Ein Reset ist einen Versuch wert, aber ein als „schwierig“ eingestufter Error 1 bedeutet fast immer ein zu tauschendes Bauteil.
