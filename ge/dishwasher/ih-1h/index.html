GE Appliances Geschirrspüler IH / 1H: heizelement-fehler

IH / 1H bedeutet: Fehler des Einlassheizers oder Temperatur zu hoch.

Kurzantwort. Der Heizstromkreis ist fehlerhaft oder das Wasser hat sich überhitzt. Lassen Sie es abkühlen; danach handelt es sich um eine Reparatur von Heizelement, Thermostat oder Relais.

Wann der Fehler auftrittjederzeit

IH / 1H beheben

  1. Trennen Sie das Gerät vom Netz und lassen Sie es 20 Minuten abkühlen.
  2. Setzen Sie das Gerät zurück und lassen Sie ein Programm laufen; kehrt der Fehler zurück, messen Sie das Heizelement und prüfen Sie das Sicherungsthermostat.
  3. Ein auf der Platine klebendes Relais ist die andere Ursache; tauschen Sie die Platine aus.

Wann aufhören und zum Reparateur gehen

Ein dauerhaft eingeschaltetes Heizelement ist gefährlich; lassen Sie die Maschine mit diesem Code nicht unbeaufsichtigt laufen.

Was es kostet

Ersatzteile: Heizelement 30–60 €; Platine 90–200 €.

Service: Der Herstellerservice für einen Vollautomaten liegt außerhalb der Garantie typisch bei 250–500 € inkl. Rückversand; freie Espressowerkstätten sind bei einem einzelnen Teil meist günstiger.

Reparatur lohnend? Hängt vom betroffenen Bauteil ab.

Fehlerprotokoll abrufen

Bei den meisten GE-Geschirrspülern halten Sie bei geöffneter Tür Start 5 Sekunden gedrückt, um in das Service-Menü zu gelangen; bei Modellen mit verstecktem Display drücken Sie Select Cycle und Start gleichzeitig 5 Sekunden lang. Der letzte Fehler erscheint im Display. Trennen Sie die Stromversorgung am Leistungsschalter für 60 Sekunden, um die Platine zurückzusetzen.

Löschen Sie das Protokoll nach der Reparatur, um zu prüfen, ob der Defekt wirklich weg ist.

Wann tritt IH / 1H typischerweise auf?

An GE Appliances Geschirrspüler tritt IH / 1H jederzeit auf. Es gibt kein zuverlässiges Muster — nehmen Sie jedes Auftreten ernst.

Kann man die Maschine mit IH / 1H weiter benutzen?

Der laufende Kaffee lässt sich meist noch fertig beziehen, aber ignorieren Sie den Code nicht: Der Defekt heilt nicht von selbst. Beginnen Sie mit den kostenlosen Prüfungen.

Verschwindet IH / 1H von selbst?

Selten. Ein Reset ist einen Versuch wert, aber ein als „schwierig“ eingestufter IH / 1H bedeutet fast immer ein zu tauschendes Bauteil.
