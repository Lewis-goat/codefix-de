Breville / Sage Oracle Touch ER19: heizelement erreicht temperatur nicht

ER19 bedeutet: Brühkopftemperatur steigt nicht wie erwartet.

Kurzantwort. Die Steuerung schaltet das Brühkopf-Heizelement ein, aber die Temperatur steigt nicht. Entweder erhält das Heizelement keine Spannung (eine ausgelöste Thermosicherung oder ein defekter Triac) oder das Heizelement selbst ist ausgefallen. Auch ein abweichender Sensor kann dieses Verhalten vortäuschen, doch Fehler auf der Heizungsseite sind weitaus häufiger.

Wann der Fehler auftrittjederzeit

ER19 beheben

  1. Prüfen Sie das Offensichtliche: Wassertank gefüllt und eingerastet, keine Meldung „Tank füllen“, Gerät an einer Steckdose, die sich keinen Stromkreis mit einem Wasserkocher oder Heizgerät teilt.
  2. Starten Sie das Gerät neu und stoppen Sie die Zeit für die Aufheizphase. Überhaupt keine Wärme nach fünf Minuten bedeutet, dass das Heizelement keine Spannung erhält: Thermosicherung oder Triac.
  3. Öffnen Sie das Gerät und prüfen Sie die Thermosicherung am betroffenen Kessel mit einem Multimeter (sie sollte nahezu null Ohm anzeigen). Ist sie unterbrochen, ersetzen Sie sie, finden Sie aber auch heraus, warum sie ausgelöst hat (Leck, Kalk, klebender Triac).
  4. Messen Sie den Widerstand des Heizelements. Eine Unterbrechung bedeutet ein neues Heizelement oder, bei ThermoJet-Geräten, einen neuen Heizblock.
  5. Sind Sicherung und Heizelement in Ordnung, schaltet die Triac-Platine nicht. Ersetzen Sie die Platine.

Wann aufhören und zum Reparateur gehen

Am Heizelement und an der Triac-Platine liegt Netzspannung an. Wenn Sie beim Prüfen unter Spannung nicht sicher sind, ist dies eine Werkstattreparatur für einen Techniker.

Was es kostet

Ersatzteile: Thermosicherung 10–20 €; Heizelement oder ThermoJet-Heizung 60–150 €; Triac-Platine 80–150 €.

Service: Der Herstellerservice für einen Vollautomaten liegt außerhalb der Garantie typisch bei 250–500 € inkl. Rückversand; freie Espressowerkstätten sind bei einem einzelnen Teil meist günstiger.

Reparatur lohnend? Eine Thermosicherung lohnt sich immer. Ein Heizelement oder eine Platine bei einem älteren Gerät ist eine Abwägung: Vergleichen Sie den Kostenvoranschlag mit einem generalüberholten Ersatzgerät.

Fehlerprotokoll abrufen

Schalten Sie die Maschine an der Steckdose aus. Halten Sie die Power-Taste an der Front gedrückt, schalten Sie die Stromversorgung an der Steckdose wieder ein und lassen Sie los, sobald das Logo erscheint. Geben Sie das Service-Passwort 00000 ein und öffnen Sie dann den Error Counter (gespeicherte Fehler) oder Live Debug (aktuelle Temperaturen und Wasserstände).

Löschen Sie das Protokoll nach der Reparatur, um zu prüfen, ob der Defekt wirklich weg ist.

ER19 beim Start oder im Betrieb?

An Breville / Sage Oracle Touch tritt ER19 jederzeit auf. Es gibt kein zuverlässiges Muster — nehmen Sie jedes Auftreten ernst.

Kann man die Maschine mit ER19 weiter benutzen?

Stopp-Signal: ER19 kennzeichnet einen Defekt, der die Maschine beschädigen kann, wenn Sie weitermachen. Erst die sicheren Erstschritte, dann aufhören.

Verschwindet ER19 von selbst?

Selten. Ein Reset ist einen Versuch wert, aber ein als „schwierig“ eingestufter ER19 bedeutet fast immer ein zu tauschendes Bauteil.
