Breville / Sage Oracle Touch ER16: kurzschluss des temperatursensors

ER16 bedeutet: Kurzschluss des Temperatursensors der Dampflanze im Betrieb.

Derselbe Code, dieselbe Lösung bei Oracle. Alles Folgende gilt für beide.

Gilt für: Oracle Touch.

Kurzantwort.Der Temperatursensor (NTC) der Dampflanze meldet einen Kurzschluss: Die Platine sieht einen Widerstand nahe null, den ein intakter Sensor nicht liefert. Quellen von Technikern nennen als wahrscheinliche Ursachen Wasser, das die Sensorkontakte überbrückt (ein Leck oder Dampf an der Sondendichtung), und einen defekten Sensor. Da der Fehler im Betrieb auftrat, ist plausibel, dass Hitze oder Dampf den Stecker erreicht. Breville veröffentlicht diese Code-Tabelle nicht; die Bedeutung stammt daher aus Service-Tabellen Dritter. ER16 wird als Kurzschluss des Temperatursensors der Dampflanze im Betrieb geführt, meist beim Aufschäumen von Milch. Er ist in Tabellen Dritter das „Betriebs“-Gegenstück zu ER15 und hat denselben Rat.

ER16 beheben

  1. Schalten Sie an der Steckdose aus und ziehen Sie den Netzstecker. Lassen Sie die Maschine eine Stunde stehen, damit Feuchtigkeit trocknet, und versuchen Sie es dann erneut. Ein Kurzschluss, der nach dem Trocknen verschwindet, deutet auf ein Leck hin, das gefunden werden sollte.
  2. Reinigen Sie Dampflanze und Spitze gründlich wie im Handbuch beschrieben und trocknen Sie die Maschine. Kehrt der Code wieder, würde ein Techniker die Lanzenbaugruppe prüfen oder ersetzen.
  3. Ein Techniker würde undichte O-Ringe an den Kesselanschlüssen und Sensorsonden ersetzen; das Leck und nicht der Sensor kann der eigentliche Fehler sein.
  4. Bleibt der Code bestehen, nachdem alles trocken ist, muss der Temperatursensor (NTC) der Dampflanze von einem Techniker ersetzt werden.
  5. Löschen Sie danach das Fehlerprotokoll und führen Sie zur Bestätigung ein vollständiges Aufheizen und einen Bezug durch.

Reinigen Sie die Lanze, trocknen Sie die Maschine und kontaktieren Sie dann Breville oder ein autorisiertes Servicecenter, wenn der Code wiederkehrt.

Wann aufhören und zum Reparateur gehen

Sehen Sie Brandspuren, riechen Sie Verbranntes oder löst die Maschine Ihren FI-Schutzschalter (GFCI / RCD) aus, hören Sie auf: Das ist ein elektrischer Fehler und nicht nur ein Sensor.

Fehlerprotokoll abrufen

Schalten Sie die Maschine an der Steckdose aus. Halten Sie die vordere Power-Taste gedrückt, schalten Sie den Netzstrom wieder ein und lassen Sie los, wenn das Logo erscheint. Geben Sie das Servicepasswort 00000 ein und öffnen Sie dann Error Counter (gespeicherte Fehler) oder Live Debug (aktuelle Temperaturen und Wasserstände). Ein Techniker-Video sagt, die Eingabemethode unterscheide sich zwischen Maschinen, die vor und nach 2018 gebaut wurden; funktioniert es nicht, versuchen Sie es daher nicht immer wieder.

Löschen Sie das Protokoll nach der Reparatur, um zu prüfen, ob der Defekt wirklich weg ist.

Mehr als die Reparatur

Wussten Sie schonDas Aufschäumen der Milch endet bei der gewählten Temperatur anhand des integrierten Sensors der Lanze; es lohnt sich daher, Rückstände in seiner Umgebung sauber zu halten.

Tipps und Tricks

  • Reinigen Sie Lanze und Spitze nach jeder Benutzung mit einem feuchten Tuch und spülen Sie sie sofort. Breville sagt, dass ein Auslassen die Milchtextur beeinträchtigen kann.Herstellerhandbuch
  • Weichen Sie eine verstopfte Lanze samt Spitze 20 Minuten in der mitgelieferten Reinigungspulverlösung ein, spülen Sie sie ab, setzen Sie die Spitze wieder auf und lassen Sie 10 Sekunden Dampf laufen.Herstellerhandbuch
  • Die Lanze im Ruhezustand in einem Krug mit Wasser zu lassen, verringert das Risiko von Verstopfungen. Reinigen Sie die Düsenöffnungen mit dem mitgelieferten Reinigungswerkzeug erst, wenn das Dämpfen beendet ist.Herstellerhandbuch

Häufige Fehler

  • Das Abwischen und Spülen nach der Milch auslassen und dann den Sensor beschuldigen, wenn sich Rückstände aufbauen.
  • Teile der Lanze in die Spülmaschine geben; das Handbuch sagt, Teile oder Zubehör dürften dort nicht gereinigt werden.

Leicht zu verwechseln mit

  • Schwacher oder fehlender Dampf ohne Code kann eine verstopfte Lanzenspitze sein, was das Handbuch unter Reinigung behandelt.
