Breville / Sage Oracle Touch ER01: temperature sensor open circuit (not detected)

ER01 bedeutet: Steam boiler temperature sensor not detected at startup.

Kurzantwort. The control board cannot read the steam boiler temperature sensor (NTC). On this code the sensor reads as an open circuit: the wire has come off, the plug is loose or corroded, or the sensor itself has failed. Because it fails the self-test at power-on, the machine refuses to start until the sensor reads again.

Selbstreparaturmittel
Wann der Fehler auftrittbeim Einschalt-Selbsttest

ER01 beheben

  1. Switch the machine off at the wall, wait 60 seconds and switch it back on. A one-off reading glitch clears; a real open circuit comes straight back.
  2. Remove the water tank, hopper and drip tray, then the base or rear panel (Phillips screws). Find the sensor plug for the steam boiler temperature sensor (NTC) on the control board, unplug it, look for green corrosion or heat marks, and push it firmly back on.
  3. Check for water where it should not be. Moisture on the board or in a connector reads as an open or short. Dry everything and look for the leak that caused it (usually a boiler o-ring or hose clip).
  4. If the code returns, replace the steam boiler temperature sensor (NTC). On the Oracle Touch it is a plug-in part; note which way the wires route before pulling the old one.
  5. Clear the stored error afterwards (see how to read the error log below) so you can tell whether it recurs.

Wann aufhören und zum Reparateur gehen

Stop and book service if you find a swollen or burnt component on the board, or if the sensor plugs are fine and a new sensor does not clear the code: that points at the control board.

Was es kostet

Ersatzteile: Genuine NTC sensor assemblies run about $25 to $95 depending on which sensor it is (steam wand and milk-jug sensors are the dear ones). O-ring kits are $10 to $20.

Service: Der Herstellerservice für einen Vollautomaten liegt außerhalb der Garantie typisch bei 250–500 € inkl. Rückversand; freie Espressowerkstätten sind bei einem einzelnen Teil meist günstiger.

Reparatur lohnend? Usually yes. A sensor plus o-rings is under $100 and 30 to 60 minutes. Only a dead control board makes the repair questionable on an older machine.

Fehlerprotokoll abrufen

Switch the machine off at the wall. Hold the front Power button, switch the wall power back on and release when the logo appears. Enter the service password 00000, then open Error Counter (stored faults) or Live Debug (live temperatures and water levels).

Löschen Sie das Protokoll nach der Reparatur, um zu prüfen, ob der Defekt wirklich weg ist.
