Breville / Sage Oracle Jet E11: grinder motor fault

E11 bedeutet: Grinder blocked causing excessive current draw.

Kurzantwort. The grinder is drawing too much current or not turning. Almost always this is beans, stones or compacted grounds jamming the burrs, or a grind setting so fine that the motor labours. A worn motor is possible after many thousands of cups.
Betroffenes Bauteilgrinder motor

Wann der Fehler auftrittjederzeit

E11 beheben

  1. Stop and let the machine sit for 30 minutes if the code mentions overheating.
  2. Remove the hopper, empty it and check for a stone or a very oily, compacted bean layer at the burr throat.
  3. Lift out the top burr and clean both burrs and the chute with the brush. Never wash burrs; moisture clogs them.
  4. Check the tamp fan / impeller under the burr is fitted and not stuck (Oracle models). A missing fan makes the grinder run continuously.
  5. Set the grind two or three numbers coarser, refit everything, and run a short grind with a small dose of beans.
  6. If the motor hums but does not turn with clean burrs, it has failed. It is a replaceable module.

Wann aufhören und zum Reparateur gehen

A burning smell means stop and let it cool; do not repeatedly retry a jammed motor.

Was es kostet

Ersatzteile: Nothing for a jam; a grinder motor is $60 to $120.

Service: Der Herstellerservice für einen Vollautomaten liegt außerhalb der Garantie typisch bei 250–500 € inkl. Rückversand; freie Espressowerkstätten sind bei einem einzelnen Teil meist günstiger.

Reparatur lohnend? Yes. Jams are free to fix; a motor is a fair price against a new machine.

Fehlerprotokoll abrufen

Open Settings on the touch screen, then About the Machine, then Software version. On that screen tap each bottom corner of the screen several times. Go back to About the Machine and a new Service center mode entry appears. Open it to view the error log.

Löschen Sie das Protokoll nach der Reparatur, um zu prüfen, ob der Defekt wirklich weg ist.

Verwandte Codes am selben Bauteil

  • E12 — Grinder speed sensor not detecting normal operation
  • E13 — Grinder motor operation timed out before completing grind cycle

Häufige Fragen

Was bedeutet E11 an der Breville / Sage Oracle Jet?

Grinder blocked causing excessive current draw. The grinder is drawing too much current or not turning. Almost always this is beans, stones or compacted grounds jamming the burrs, or a grind setting so fine that the motor labours. A worn motor is possible after many thousands of cups.

Kann man E11 selbst beheben?

Schwierigkeit: einfach. Stop and let the machine sit for 30 minutes if the code mentions overheating. Remove the hopper, empty it and check for a stone or a very oily, compacted bean layer at the burr throat.

Was kostet die Reparatur von E11?

Nothing for a jam; a grinder motor is $60 to $120. Der Herstellerservice für einen Vollautomaten liegt außerhalb der Garantie typisch bei 250–500 € inkl. Rückversand; freie Espressowerkstätten sind bei einem einzelnen Teil meist günstiger.

Lohnt sich die Reparatur?

Yes. Jams are free to fix; a motor is a fair price against a new machine.

E11 beim Start oder im Betrieb?

An Breville / Sage Oracle Jet tritt E11 jederzeit auf. Dieser Zeitpunkt ist ein nützlicher Hinweis auf die Ursache.

Kann man die Maschine mit E11 weiter benutzen?

In der Regel ja — E11 ist eher lästig als gefährlich. Reparieren Sie in Ruhe, lassen Sie es nur nicht monatelang liegen.

Verschwindet E11 von selbst?

Oft, ja. Der erste Schritt (stop and let the machine sit for 30 minutes if the code mentions overheating) löst allein einen Teil der Fälle. Kommt der Code sofort zurück, ist das Bauteil wirklich defekt.

Wie lange dauert die Reparatur?

Fünfzehn bis dreißig Minuten mit einfachem Werkzeug, Ersatzteil in der Hand.
